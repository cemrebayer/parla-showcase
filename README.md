# Parl'a Cafe

**A digital home for a warm, social café in Bahçeşehir, İstanbul.**

[Visit the live website →](https://parlacoffee.com)

---

## The project

Parl'a is a boutique café concept founded by two sisters in 2026. The website was designed to translate the café's welcoming atmosphere into a refined digital experience: warm, editorial, intimate and easy to use on a phone.

The visual direction brings together cream, deep burgundy and warm gold details with expressive serif typography, café photography and gentle motion.

## Highlights

- A responsive café website for mobile, tablet and desktop
- Turkish and English content, selected from the visitor's device language
- A QR-ready public menu route
- A protected menu management area for future product and price updates
- A Supabase-backed menu data structure
- Automatic production deployment through Vercel
- A custom domain with HTTPS enabled
